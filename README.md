# Cartify Frontend

E-commerce web application built with React and Vite.

## Features
- Product catalog with instant search, category filters, and price range filters
- Product details with stock status, image preview, and similar recommendations
- Shopping cart with quantity management and session persistence
- Cash on Delivery (COD) checkout with delivery address form
- Order tracking timeline with live status updates
- Store Admin Dashboard for catalog and order management
- Light and dark theme toggle

## Tech Stack
- React 19
- Vite
- React Router DOM
- Lucide React (Icons)
- Vanilla CSS

## Getting Started

1. Install project dependencies:
npm install --legacy-peer-deps

2. Configure environment variables in `.env`:

VITE_API_BASE_URL=http://localhost:8000/api/v1


3. Run the development server:

npm run dev


4. Open `http://localhost:5173` in your browser.

## Build
To create a production build:

npm run build
